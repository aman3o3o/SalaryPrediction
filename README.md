# SalaryPrediction

A machine learning project to analyze salary trends and predict annual salary based on job and agency-related features.

## Key Work Done
- Cleaned & preprocessed features : jobtitle, agency, agency id, hiredate, annual salary
- Exploratory Data Analysis (EDA):
- salary trends across agency, job title and hire year
- Built prediction models and compared performance using feature importance and accuracy metrics

## Technologies used
- Python | Pandas | NumPy
- Matplotlib | Seaborn
- Scikit-learn
- Jupyter notebook
